# Chone Fit Lab (3D viewer)

A 3D model of the glove's back. It shows the Chone (the leather back) over the two foam moulds. You can draw bend lines and curl the pieces, move and resize them, and check how far the Chone's stitch line reaches down the foam edge once the glove is curled into a fist.

| File | What it is |
| --- | --- |
| `chone-fit-lab.html` | The viewer: one page with all its code inside (three.js 0.160.0 from a CDN) |
| `glove-data.js` | Flat triangle meshes of the Chone and both moulds, with the DXF piece each one is (its link, see below). Generated by `scripts/export_3d.py`, so don't edit it by hand. |
| `config/` | Saved viewer setups (JSON from **Save config**). Git-ignored, so they stay on your machine. |
| `TODO.md` | Planned and in-progress features |

## Run it

Run the viewer's server from the repo root, instead of opening the file directly:

```sh
python3 scripts/serve_viewer.py
# then open http://localhost:8000/viewer/chone-fit-lab.html
```

It serves the whole repo, so the page can read the DXFs in `dxf/`. The **Edit pattern** tab saves edited DXFs through it, straight into `dxf/`, with no file dialogs. It only listens on this computer and only writes `.dxf` files inside `dxf/`. A plain `python3 -m http.server` also shows the viewer, but then saving falls back to the browser's file dialogs.

Rebuild `glove-data.js` after changing the pattern (run this from the repo root):

```sh
uv run --with ezdxf --with shapely --with matplotlib --with scipy \
  python scripts/export_3d.py "dxf/Laces Boxing 14OZ (1).dxf" viewer/glove-data.js
```

## Trying a new DXF version of a piece

To test a new version of a piece with all your bend lines and settings, go to the **Items** tab, choose the item and click **Replace outline from DXF…**. Choose the new DXF. The dialog picks the outline in it that lines up best with the item, and you can click a different one. It works out the mirroring and turn for you and places the new outline so the parts that didn't change sit exactly where they were. If it's a changed Mould 1 thumb, only the thumb moves. Bend lines, position, thickness and the other items all stay. For a leather item you can also pick its stitch line. **Undo** (⌘Z) puts the old outline back. Save the result under a new config name to keep both versions.

## Editing a pattern piece (Edit pattern tab)

The **Edit pattern** tab reshapes an item's flat outline with a pen tool, and the 3D view follows as you go. The panel gets wider in this tab.

1. Pick the item at the top. It already knows which DXF piece it is (see "Every item knows its DXF" below).
2. **Click the outline** to add a point. You shape the stretch between two points:
   - **Drag the line** to curve it.
   - **Drag a point** to move it, even if it's the only one. The line to the next point stretches to follow. On a long stretch, only the 2" beside the point bends, and the rest of the outline stays put.
   - **Drag a point's handles** to change how the curve leaves it. Alt-drag a handle to make the point a corner.
   - Select a point and press **Delete** to remove it.
   - Dragging a line or a handle turns that stretch into one curve. If it's too long or curvy for that, the viewer says so; add a point in it first.
3. Drag the background to pan, scroll to zoom, and use **Fit to view** to see the whole piece again. **Show the DXF outline** draws the original for comparison. ⌘Z undoes each step, and **Reset to the DXF outline** starts over.
4. **Save as new DXF…** asks for a name and writes a copy of the item's DXF into `dxf/` with only this piece's outline changed. The rest of the file stays as it is: labels, notches and the other pieces. **Overwrite** writes back into the item's own DXF after asking. Either way the piece is saved exactly as shown, as a smooth curve, and the item then points at the saved file.

The outline is the only thing edited: a leather item's stitch line stays as it is.

## Every item knows its DXF

Each item in a config records which DXF piece it is, as `source`: the file (from the repo root, like `dxf/Laces Boxing 14OZ (1).dxf`), the piece's handle, and how it was mirrored, turned and moved into place. It also stores that piece's outline as curves, as `path`. The built-in Chone, Mould 1 and Mould 2 carry theirs in `glove-data.js`. Items you add or replace from a DXF get theirs automatically. That assumes the DXF lives in `dxf/`.

Configs from before this don't load. To add the links to one, run:

```sh
uv run --with ezdxf --with shapely --with scipy --with matplotlib \
  python scripts/link_configs.py "viewer/config/<name>.json"
```

It finds each item's piece in the DXFs in `dxf/` and backs the config up first, into `viewer/config/backup-<date>/`.

## Saving your setup

The viewer remembers your last setup in your browser. To keep a setup or move it to another machine, use the **Config** tab. Click **Choose folder…** once and pick `viewer/config/`. The box then shows the folder, and the page remembers it across reloads. After that, **Save config** writes the file (named in the **File name** box) straight into that folder with no dialog, and asks before replacing a file. **Load config…** opens the picker in that folder. After a reload, Chrome may ask once to let the page edit the folder again. Safari and Firefox can't pick a folder, so Save downloads the file instead. `viewer/config/` is git-ignored, so copy a config file across yourself to use it on another machine.
