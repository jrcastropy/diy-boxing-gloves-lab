# Chone Fit Lab (3D viewer)

A 3D model of the glove's back. It shows the Chone (the leather back) over the two foam moulds. You can draw bend lines and curl the pieces, move and resize them, and check how far the Chone's stitch line reaches down the foam edge once the glove is curled into a fist.

| File | What it is |
| --- | --- |
| `chone-fit-lab.html` | The viewer: one page with all its code inside (three.js 0.160.0 from a CDN) |
| `glove-data.js` | Flat triangle meshes of the Chone and both moulds. Generated by `scripts/export_3d.py`, so don't edit it by hand. |
| `config/` | Saved viewer setups (JSON from **Save config…**). Git-ignored, so they stay on your machine. |
| `TODO.md` | Planned and in-progress features |

## Run it

Serve the folder instead of opening the file directly, because the page loads `glove-data.js` and three.js modules:

```sh
cd viewer && python3 -m http.server 8000
# then open http://localhost:8000/chone-fit-lab.html
```

Rebuild `glove-data.js` after changing the pattern (run this from the repo root):

```sh
uv run --with ezdxf --with shapely --with matplotlib --with scipy \
  python scripts/export_3d.py "dxf/Laces Boxing 14OZ (1).dxf" viewer/glove-data.js
```

## Saving your setup

The viewer remembers your last setup in your browser. To keep a setup or move it to another machine, use **Save config…** and save the JSON into `viewer/config/`. Use **Load config…** to open it again. In Chrome and Edge, you only browse to `viewer/config/` the first time. After that, both dialogs open there by themselves. `viewer/config/` is git-ignored, so copy a config file across yourself to use it on another machine.
